# 第 7 天 LINE 置頂提醒設計

## 已核定規則

- 對象包含 14 天體驗、199／399／799 月繳與年繳，以及 B399／B799 21 天免繳封測。
- 以目前資格的方案啟用時間為基準，滿 7 天後推播一次。
- 功能首次由正式排程執行時建立啟用切點；啟用切點以前已到期的舊會員不補發。
- 同一資格期間只成功發送一次。失敗可由排程重試，但 LINE retry key 必須固定，避免重複送達。
- 推播內容提醒會員將「每日平安」官方 LINE 置頂，系統不宣稱能代替會員自動置頂。
- 每次嘗試都寫入既有 `notification_logs`，保存會員 LINE UID、當時方案、方案來源、預定時間、實際時間、成功／失敗及錯誤詳情。
- 後台推播紀錄顯示方案與預定發送時間；失敗仍沿用繁體中文原因與處理建議。

## 啟用時間判定

- 一般 14 天體驗：`trial_started_at`
- B399／B799 免繳封測：`beta_started_at`
- 付費方案：優先使用 `membership_started_at`；舊資料則依 `paid_until - 方案天數` 推算目前資格起點

## 防止補發與重複

狀態根節點保存 `day7_pin_reminder_enabled_at`。首次執行只建立此欄位，不發送。會員的 `due_at = activated_at + 7 天`；只有 `due_at >= enabled_at` 且尚未成功記錄該資格鍵時才可發送。

資格鍵由方案、方案來源與啟用時間組成。成功後寫入會員的 `day7_pin_reminder_keys_sent`。失敗不寫入成功鍵，下一次排程可重試。
