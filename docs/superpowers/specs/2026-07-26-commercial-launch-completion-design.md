# 每日平安商業上線完成設計

## 定案範圍

本文件整合目前所有已確認、尚未完成或只完成部分的工作，作為公開封測與正式商業營運的唯一執行順序。

已取消：

- 永久免費正式方案。
- 邀請核心守護人延長試用 7 天。
- 24 小時或無期限即時定位。
- 以不同 Provider 的 LINE user ID 猜測或自動合併會員。

正式體驗與封測政策：

- 一般新會員保留一次 14 天「新會員安心體驗」，不是永久免費方案。
- 21 天完整功能只提供列入封測名單的人，與一般 14 天體驗分開計算。
- 封測結束不自動扣款。
- 到期後顯示 199／399／799 正式方案，未付費則暫停付費權益。
- 新增守護人不延長體驗、封測、方案或資料保留時間。

## 三階方案

月費固定為 NT$199、NT$399、NT$799。年費採付 10 個月、使用 12 個月：

- 199 年費：NT$1,990。
- 399 年費：NT$3,990。
- 799 年費：NT$7,990。

### 功能矩陣

| 功能 | 199 基礎版 | 399 進階版 | 799 尊榮版 |
|---|---|---|---|
| 核心定位 | 個人隨身警報器 | 家庭／伴侶守護網 | 全家傳承守護 |
| 緊急位置 | 15 分鐘位置快照 | 1／3 小時安全守護 | 1／3／6／8 小時安全守護 |
| 移動軌跡 | 無 | 僅安全守護期間必要節點 | 僅安全守護期間必要節點 |
| 最長追蹤 | 15 分鐘 | 3 小時 | 8 小時 |
| 月曆 | 簽到勾選＋每日祝福 | 國定假日、節日＋每日祝福 | 完整農民曆、節氣、家人生日＋每日祝福 |
| 備忘錄 | 無 | 手動陽曆備忘錄，不自動提醒 | 完整備忘錄＋生日、節氣與家庭提醒 |
| SOS | 核心守護人 | 核心守護人＋守護群 | 核心守護人＋守護群 |
| 群組同步報平安 | 可選，一次性為預設 | 可選，一次性為預設 | 可選，一次性為預設 |

位置資料只為當次安全事件保存必要資訊。最長 8 小時，不提供全天監控或永久軌跡。

### 農民曆排版

799 專屬農民曆遵守：

- 「宜」使用暖色、較大字、最多三項。
- 「忌」使用淺灰、較小字，不以恐嚇式文案呈現。
- 節氣與沖煞放在最下方小字。
- 每日祝福優先於宜忌，讓頁面先傳達安心感。

### 權益來源

所有頁面與 API 必須由同一份後端 `plan_rules` 產生，不得在 HTML 另寫一份不同數字。月費與年費在核心功能相同；年費差異只限已明確列出的年度優惠，不得自行增加定位時數或守護人名額。

既有尚未由最新藍圖明確指定的核心守護人與緊急聯絡人數量，先保持目前後端值，不在本次偷偷修改；價目表必須標示實際後端回傳數字。

## LINE／LIFF 帳號安全搬家

依 `2026-07-26-liff-provider-migration-design.md`：

- 舊、新 LIFF 雙邊登入證明。
- 10 分鐘一次性搬家碼。
- 網址與日誌不傳舊 user ID 或 Token。
- 方案、提醒、簽到、守護關係、訂單、客服與隱私申請一併搬移。
- 失敗原子回復，成功後舊身分不得重建重複會員。

安全搬家完成前，不重新發布新圖文選單，也不要求正式客戶重新填寫資料。

## 報平安與群組同步

### 個人通知

按下「今日已平安」後：

- 立即顯示「正在報平安」，避免無回應等待。
- 後端成功後才顯示「今日已平安」。
- 對方案允許範圍內的所有核心守護人一次發送 LINE 平安通知，不採逐一遞補。
- 畫面顯示成功人數、失敗人數與可理解的失敗原因。

### 群組同步

報平安按鈕下方提供「同步至守護群組」：

- 預設關閉。
- 開啟時可選「僅這一次」或「持續開啟」；預設「僅這一次」。
- 當日成功報平安後，僅這一次狀態於隔日凌晨自動關閉。
- 引導文案：「建議於出遊／夜歸時開啟；系統將於隔日自動關閉，避免打擾群組。」
- 可填簡短備註，例如「媽媽今天去爬山，晚上回家」。
- 一般報平安每個守護群每日最多一則；SOS 與 SOS 取消不受此限制。
- 不宣稱能取得 LINE 群組成員已讀名單，也不宣稱能替每位群組成員設定不同靜音時段。

## SOS／需要幫忙

### LINE 聊天室

圖文選單「需要幫忙」使用 postback 在 LINE 聊天室完成三次確認，不跳 LIFF：

1. 第一次顯示「再按 2 次」。
2. 第二次顯示「再按 1 次」。
3. 第三次才建立 SOS 並通知。

每一步顯示大字進度、取消按鈕與逾時狀態。不同帳號、超過時限或已取消不得沿用舊進度。

### 網頁

保留原本浮動 SOS 按鈕與目前頁面，不跳首頁；三次按壓必須有畫面進度，第三次才送出。

### 收件人與結果

- 一次通知方案範圍內所有核心守護人及有效守護群。
- 結果畫面顯示實際成功收件人名稱、群組名稱、失敗對象、失敗原因與發送時間。
- 不顯示 LINE user ID。
- 若沒有任何成功收件人，不能只顯示「已送出」。

### 取消

- 成功送出後 10 分鐘內可以取消。
- 取消訊息只送給原 SOS 實際成功的收件人，包括核心守護人與守護群。
- 取消後顯示取消時間、通知成功與失敗名單。
- 重複取消不重複發送。

## 守護角色與邀請

使用者介面只使用：

- 核心守護人：完成 LINE 綁定，接收報平安、未報平安、SOS、安全守護通知。
- 緊急聯絡人：保存電話等緊急聯絡資訊，未完成 LINE 綁定時不得顯示為已收到 LINE 通知。
- 守護群：獨立群組收件單位，不稱為一般守護人。

首頁、會員中心、Q&A、歡迎詞、後台與通知模板全部統一名稱。

一鍵邀請直接開啟 LINE `shareTargetPicker`，不先跳首頁。名額顯示必須使用「上限－已使用」，例如 1／15 時顯示可新增 14 位。

## 21 天封測後台

第一批：

- 10 位認識的測試者。
- 21 天。
- 開放 799 功能以完整找錯。

第一批連續 7 天沒有重大錯誤後才開第二批：

- 30 位陌生測試者。
- 20 位使用 399 功能。
- 10 位須實測家庭 LINE 守護群流程。

後台功能：

- 新增、匯入、搜尋、停用封測名單。
- 顯示邀請狀態、登入狀態、第幾天、剩餘天數、方案、最後活動與錯誤數。
- 批次開通，但不得批次延長或自動扣款。
- 收集回饋、重現步驟、裝置、LINE 版本與處理狀態。
- P0／P1 錯誤阻止下一批開放。

## 方案到期與隱私

方案到期：

- 暫停付費功能，不刪除會員基本資料。
- 核心守護人、緊急聯絡人與必要安全資料保留至少 30 天，供續費恢復。
- 顯示到期日、暫停功能與重新啟用步驟。
- 不自動扣款，除非未來另行取得明確授權。

隱私申請：

- 資料匯出、歷史刪除與帳號刪除分開。
- 後台顯示申請日、法定／承諾期限、處理者、狀態與完成證據。
- 帳號刪除在 30 天內完成；依法需保存的付款紀錄去識別化保留。
- 位置分享與 SOS 頁面記錄使用者同意版本與時間。

## 客服工單

既有 LINE 客服留言升級為正式工單：

- 類型：操作、帳務、守護綁定、通知失敗、定位、隱私、資安事件。
- 優先級：P0、P1、P2、一般。
- 狀態：待處理、處理中、等待用戶、已解決、已關閉。
- 指派、標籤、期限、內部備註與 LINE 回覆。
- P0 個資外洩或 SOS 通知異常立即顯示紅色警示。
- 不得在工單內顯示 Token、完整連線字串或付款卡號。

## 系統安全中心與 R2

依 `2026-07-26-admin-security-center-design.md`：

- Render Postgres 付費／到期狀態與第 N 天提醒。
- Cloudflare R2 每日 AES-256-GCM 異地備份。
- 14／7／3／1 天付費與續費提醒。
- 備份校驗、每月還原演練與維護紀錄。
- Token／Secret 只顯示是否設定，不顯示原文。
- 管理後台手機與桌面 UI 美化，重要儲存按鈕固定可見。

## 藍新正式金流

正式上線前完成：

- 正式商店與正式 Merchant 憑證。
- 199／399／799 月費及年費訂單。
- 付款通知簽章、冪等處理與金額核對。
- 付款成功才開權益；失敗不得誤開。
- 退款申請、人工審核、退款結果與權益結束。
- 每日訂單／藍新對帳差異表。
- Sandbox 與 Production 完全分離，不在後台顯示 Hash Key／IV。

## 商業數據與營運

後台至少顯示：

- 加入好友、LIFF 登入、完成搬家、綁定第一位核心守護人。
- 第一次報平安、第一次安全守護、第一次 SOS 測試。
- 價目表瀏覽、建立訂單、付款成功與續費。
- LINE 推播成功率、失敗率、封鎖／非好友原因。
- 封測錯誤、客服量、隱私申請與備份健康。

不得把精確位置、電話、訊息內容或 LINE user ID送入分析事件。

## 執行順序與部署閘門

### P0：資料與救命流程

1. 帳號安全搬家。
2. Postgres 安全檢查與 R2 備份。
3. LINE／網頁三次 SOS、結果與取消通知。
4. 新 LIFF 真機綁定、報平安與定位測試。

### P1：日常核心體驗

1. 報平安通知所有核心守護人。
2. 一次性群組同步與每日一次限制。
3. 智能提醒儲存按鈕固定、報平安速度、一鍵邀請。
4. 角色名稱、Q&A、歡迎詞與名額顯示統一。

### P2：封測與營運

1. 21 天封測名單後台。
2. 方案到期暫停。
3. 隱私申請工作流。
4. 正式客服工單。
5. 後台安全中心 UI／UX。

### P3：方案與營收

1. 後端權益矩陣改為最新 199／399／799。
2. 價目表與完整比較表。
3. 藍新正式付款、退款與對帳。

### P4：正式上線

1. 全站環境變數與秘密掃描。
2. Python、前端、API、按鈕、權限與手機真機測試。
3. 備份還原演練。
4. 獨立程式複審。
5. PR、合併、Render 部署與部署後驗證。

任何階段只要出現資料搬移失敗、SOS 錯誤通知、備份不可還原、權限繞過或正式金流金額不一致，都停止部署。

## 完成定義

商業版本只有在以下全部成立時才可稱為完成：

- 新舊帳號資料安全搬家完成。
- 報平安、SOS、取消與定位由實際 LINE 帳號端到端成功。
- 所有方案頁、後台與 API 權益一致。
- 21 天封測、到期、客服與隱私流程可由後台完成。
- 付費 Postgres 與 R2 備份正常，至少完成一次還原演練。
- 藍新正式交易、失敗、重複通知、退款與對帳通過。
- 無 Critical／Important 審查問題，完整測試與部署後驗證通過。
