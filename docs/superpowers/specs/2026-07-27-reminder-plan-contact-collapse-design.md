# 提醒方案與聯絡人收合設計

## 已核准規則

- 399 月費與年費每日可選 1～2 次提醒，預設 2 次。
- 799 月費與年費每日可選 1～3 次提醒，預設 2 次。
- 預設時段為 12:00、18:00；799 選 3 次時第 3 次為 22:00。
- 當日完成簽到後，當天剩餘簽到提醒全部停止。
- 月費與年費提醒次數相同；年費差異放在價格與其他守護權益。
- 公開方案頁、會員設定、後端限制、README、FAQ 文案與測試必須一致。

## 聯絡人卡片

核心守護人與緊急聯絡人沿用同一套可收合卡片。已儲存項目預設收合，摘要顯示姓名、關係與綁定狀態；點擊後顯示聯絡方式、編輯、刪除及邀請動作。同一名單一次只展開一張，新增與頁面主要操作保持可見。

## 邊界

本次不修改 Task 3 的七天邀請效期、安全 Token、雙向綁定交易與通知儲存順序；也不部署。既有「邀請延長試用 7 天」已取消，因此不再顯示為方案賣點。

## 驗收

- 方案限制與公開文案測試通過。
- 12:00／18:00／22:00 預設時段測試通過。
- 簽到後同日剩餘排程不推播測試通過。
- 收合卡片具備鍵盤焦點、`aria-expanded`、預設收合與單張展開。
- 不修改既有未提交主視覺圖片。
