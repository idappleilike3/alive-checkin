# 每日平安：守護關係、智能提醒與 SOS 一致性修正規格

日期：2026-07-29

## 問題

1. 智能提醒區只顯示說明文字，缺少可操作的新增、編輯、刪除與啟用功能。
2. 799 方案的日期備忘提醒沒有清楚入口，也沒有在平安紀錄上方提示使用者需要先建立紀錄。
3. 14 天體驗已完成守護人綁定，仍顯示未綁定或新人引導。
4. 同一邀請人與受邀人可重複建立兩筆守護關係，第二筆顯示不明確的「一般」。
5. SOS 連按三次後，前台判定沒有守護人，訊息未送達。
6. 缺少「誰在守護我／我正在守護誰」雙方通知與狀態頁。

## 定案

### 14 天體驗
- 權益固定比照 199 活著版。
- 體驗綁定狀態只採用已接受的正式守護關係。
- 已有至少一位有效核心守護人時，不再顯示新人綁定引導。

### 守護關係唯一資料來源
- 以 inviter_line_user_id + guardian_line_user_id 建立唯一鍵。
- 同一組雙方只能存在一筆有效關係。
- 重複接受邀請時更新原紀錄，不新增第二筆。
- 移除「一般」顯示，角色只允許：核心守護人、緊急聯絡人、正在守護的人。

### 智能提醒
- 首頁／會員中心提供新增、編輯、刪除、啟用／停用。
- 欄位：標題、日期、時間、是否重複、備忘內容、通知本人、通知核心守護人。
- 799 方案在「平安紀錄」上方顯示日期備忘提醒卡與新增按鈕。
- 尚未建立紀錄時提示：先新增日期與備忘，系統才會在指定時間提醒。

### 雙方守護頁
- 「誰在守護我」：姓名、關係、綁定狀態、通知權限、最近通知狀態。
- 「我正在守護誰」：姓名、每日報平安時間、今日狀態、最近 SOS／逾時通知。
- 雙方都可看到邀請接受、解除、SOS 已送達、已接手、已安全等狀態。

### SOS
- SOS 收件人必須直接讀取同一份有效核心守護關係資料。
- 連按第三次後立即建立事件並送出，不得再次使用舊 contacts／guardians 判斷。
- 若沒有有效收件人，明確顯示原因與修復入口。
- 若有收件人，顯示每位收件人的送達／失敗／回應狀態。

## 驗收

1. 同一人重複開啟邀請，不會新增第二筆。
2. 已綁定會員重新整理後不再看到未綁定或新人引導。
3. 799 可在平安紀錄上方建立日期備忘提醒。
4. 智能提醒可新增、編輯、停用與刪除。
5. SOS 第三次點擊後，至少一位有效核心守護人收到 LINE 通知。
6. 求助者與守護人雙方都能看到事件狀態。
7. 14 天體驗權益與 199 方案一致。
