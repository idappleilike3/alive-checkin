# 每日安心圖文卡設計規格

## 目標

將已確認的參考圖轉成真正的動態 LINE Flex 與詳情網頁功能。參考圖只作為溫暖插畫、成熟清爽排版與老人友善大字的視覺依據，不把參考圖本身上傳成固定卡片。

## 卡片內容

- 依台北時間自動顯示早安、午安或晚安問候；不依賴固定示意圖片才能運作。
- 早安、午安、晚安各使用一張依已確認 UI/UX 案例製作的同系列母女情境 Hero；媽媽必須拿手機，三張分別以晨光、暖陽、柔和夜色呈現，並隨台北時間自動切換。
- 使用會員已填寫的「縣市＋鄉鎮市區」查詢天氣，卡片只顯示縣市。
- 顯示天氣描述、最低／最高溫及降雨機率，例如「臺中市｜晴時多雲｜26～32°C｜降雨機率 30%」。
- 未填地區時顯示「請設定所在地區」；氣象服務失敗時顯示「天氣資料暫時無法更新」，不得套用其他縣市或示意數字。
- 每天只顯示一則 30～50 字的「今日安心資訊」，不把多則內容同時塞進卡片。
- 正常日顯示每日鼓勵短句；節日顯示節日祝福。

## 資訊優先順序

1. 颱風、豪雨、高溫或低溫等重要天氣資訊。
2. 緊急生活安全資訊。
3. 政府或醫療機構提供的健康提醒。
4. 一般生活安全或日常感恩短句。

健康資訊不得包含偏方、廣告、未驗證說法或製造恐慌的疾病新聞。每則資料保存標題、摘要、來源名稱、來源網址與更新時間。

節日當天以節日祝福取代一般安心資訊。連續報平安第 100 天與第 365 天以里程碑感謝取代新聞／一般安心資訊，且第 100／365 天優先於節日規則。

## 操作與版面

卡片保留四個大字、近似同高的操作按鈕：

1. 「✅ 我平安」：綠色主要操作，只比其他按鈕稍醒目，使用既有 `action=checkin` postback。
2. 「🛡️ 安全守護」：進入既有安全守護 LIFF。
3. 「需要幫忙」：進入既有 SOS LIFF。
4. 「🔔 查看今日安心提醒」：進入新的會員專屬詳情頁。

Logo 與「每日平安」品牌文字同行，不把 Logo 做成另一顆巨大按鈕。所有主要文字靠左、可換行，iPhone 與 Android 不截字。

## 詳情頁

新增 `daily-care.html`，登入後顯示：

- 會員縣市的天氣、溫度、降雨機率與簡短穿著／外出提醒。
- 當天唯一一則重要天氣、生活安全、健康資訊或里程碑內容。
- 節日祝福或每日鼓勵短句。
- 資訊來源、可點擊的「查看完整資訊」與更新時間。
- 返回「每日平安」首頁的按鈕。

API 不接受客户端传入其他会员 UID；以既有 LIFF 身分验证取得当前会员，避免查看他人的地区资料。

## 資料與降級策略

- 氣象查詢封裝為獨立模組，正式來源使用中央氣象署公開資料；授權設定缺少、逾時或格式異常時回傳明確的 unavailable 狀態。
- 每次成功資料可快取，避免每位會員每次推播都打一次外部 API；過期快取只可標示最後更新時間，不得偽裝成即時資料。
- 安心資訊使用版本化、已審核的內建資料集；重要天氣警示可覆寫當日一般內容。
- LINE 卡片與詳情頁共用同一份 `build_daily_care_context(profile, now)` 結果，避免兩邊文案、天氣或優先順序不一致。

## 測試與上線

- 單元測試覆蓋早／午／晚、已設定／未設定地區、氣象成功／失敗、內容優先順序、節日與第 100／365 天。
- Flex 測試確認四顆按鈕、動作 URI、近似同高與大字可換行。
- API 測試確認身分驗證、來源與更新時間、不可讀取他人資料。
- 网页行为测试确认资料呈现、失败提示和返回按钮。
- 所有外部气象请求在测试中使用本地假资料，不发送真实 LINE 推播。
- 验证通过后只合并本功能分支到 `main`，触发 Render；不得带入原工作区的旧修改。
