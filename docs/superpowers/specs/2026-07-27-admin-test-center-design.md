# 後台測試中心設計

## 目標

在既有管理後台加入安全測試中心，讓管理員在部署前後以指定 LINE 測試帳號驗證主要通知與整合狀態。

## 安全規則

- 僅已登入管理員可讀取；執行測試必須通過 CSRF。
- 只允許傳送至 `TEST_LINE_USER_IDS` 白名單內帳號。
- 測試不扣款、不改方案、不計入正式推播額度、不觸發正式會員排程。
- 測試付款與恢復設定只做模擬結果，不呼叫金流、不寫入會員權益。
- 每次執行記錄測試項目、目標遮罩、結果、時間與錯誤摘要，不儲存密碼、Token 或金鑰。

## 功能

測試項目包含每日問候、14 天體驗提醒、21 天封測提醒、付費到期提醒、付款後恢復、SOS／取消／定位、守護人邀請、19:00 封測詢問與不再提醒。R2、GA4、LINE、金流則提供唯讀設定狀態；R2 可執行獨立測試備份。

後台顯示白名單、外部服務狀態、測試按鈕及最近執行紀錄。未設定白名單或服務憑證時，按鈕停用並顯示明確原因。

## 驗證

以 API 權限、白名單限制、無正式資料異動、執行紀錄、前端按鈕及完整回歸測試驗證。
