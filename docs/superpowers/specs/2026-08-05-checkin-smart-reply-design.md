# 報平安智慧回覆設計

## 目標

本人完成報平安時顯示真實完成時間、每日祝福、目前等級、連續天數與新聞資訊；核心守護人只顯示會員已報平安、完成時間與新聞資訊，不揭露會員成長進度。

## 訊息規則

- 本人訊息：完成狀態、完整時間、當天日期星期、祝福語、等級與連續天數、選配安全新聞、下次提醒、放心結語。
- 守護人訊息：會員姓名、完整時間、選配安全新聞、放心結語；不顯示祝福語、等級、連續天數或會員的下次提醒。
- 安全新聞沿用 `daily_care.build_daily_care_context()` 的 `daily_news` 與 `has_important_news` 判定；無重大消息時顯示「今日暫無重要安心提醒」，讓雙方每天都看得到新聞狀態。
- 日期、星期與下一次提醒一律依 Asia/Taipei 實際報平安時間及會員設定計算。
- 重複點擊當天報平安不再次推播守護人。

## 錯誤處理與驗證

- 缺少新聞、祝福或等級資料時使用既有安全預設，不產生空白欄位。
- 新增本人與守護人的行為測試，覆蓋有重大新聞及無重大新聞兩種情況。
- 執行相關測試、完整 Python 測試與語法檢查後才提交部署。
