# 後台個人化圖文卡設定、預覽與發送設計

## 目標

把目前難以理解的新版圖片卡推播區改成兩個清楚區域：管理員可先設定及預覽 LINE 圖文卡，再選擇單一會員或全部符合資格會員發送。任何預覽、編輯或儲存動作都不得觸發 LINE 推播。

## 操作流程

### 一、圖文卡設定

1. 選擇「每日平安預設卡」或既有自訂範本。
2. 可修改祝福文字、主圖網址及四個按鈕的顯示文字與連結。
3. 右側即時顯示接近 LINE Flex Message 的手機卡片預覽。
4. 可儲存為範本、更新既有範本、複製範本或恢復系統預設。
5. 「每日平安」正式 Logo 固定由系統提供，後台不可上傳、替換、變色、裁切或改比例。

### 二、會員預覽與發送

1. 按「載入可推播會員」。
2. 下拉選擇會員；空名單或載入失敗時顯示中文原因與下一步。
3. 按「預覽這位會員的圖片卡」。系統套入會員真實暱稱、目前等級、連續天數、最高徽章與下一級進度，但不發送。
4. 預覽完成後才啟用「確認並發送給這位會員」。發送前再顯示會員姓名與遮罩 UID。
5. 全部會員發送獨立放在頁面下方；先列出符合資格會員，再經第二次確認才能群發。

## 範本資料與安全規則

- 範本包含：名稱、祝福文字、主圖 HTTPS 網址、四個按鈕的文字與 HTTPS 連結、建立與更新時間。
- 會員個人資料不寫入範本；姓名、等級與進度只在預覽或發送當下套入。
- 圖片及按鈕網址只接受 `https://`，並拒絕空白主圖、`javascript:`、`data:` 及其他不安全協定。
- 系統預設範本不可刪除；自訂範本可建立、更新及刪除，刪除前必須確認。
- 待重新註冊、已封鎖、資格失效或暫停會員不出現在收件名單。
- 單發與群發都沿用最高管理員權限、操作稽核及發送結果紀錄。

## 介面設計

- 使用既有每日平安後台的藍綠色系與大字體，不重做整個管理後台。
- 以「圖文卡設定」與「會員預覽與發送」兩個頁籤分流；每區只顯示當下需要的控制項。
- 每個步驟提供一句短教學；未完成前一步時，下一步按鈕保持停用並直接說明原因。
- 桌面版為設定表單與手機預覽並排；手機版改為直向，先設定、後預覽。
- 預覽卡以固定 Logo 與四個按鈕作為辨識重點，避免加入與操作無關的裝飾。

## API 與資料流

- 範本管理 API：列出、建立、更新、刪除及恢復預設範本。
- 圖文卡預覽 API：接收範本與選定會員 UID，回傳 Flex Message 與預覽所需的安全資料，不呼叫發送器。
- 現有收件名單 API 保留，但錯誤訊息改為後台可直接理解的中文。
- 現有發送 API 增加範本識別碼或已驗證內容；後端再次確認會員資格、範本安全與 `confirmed: true` 後才發送。

## 驗收條件

- 管理員不看額外說明，也能依畫面上的三步驟完成單一會員預覽。
- 按預覽、儲存或切換範本時，LINE 發送器呼叫次數維持零。
- 預覽使用會員真實進度，且不會將會員資料保存到共用範本。
- 不安全網址不能儲存或發送，並顯示中文修正方式。
- 單一發送只送選定 UID；群發沒有完成二次確認時送出人數為零。
- 手機與桌面皆可操作，鍵盤焦點清楚，並尊重減少動畫設定。

## 節日背景生成（A 方案追加定案）

- 只生成主視覺背景；Logo、會員暱稱、祝福文字、等級進度與四個可點擊按鈕由系統疊加。
- 提供內建節日範本與自動生成腳本，生成後可輸入修改要求再重新生成。
- 節日庫包含元旦、農曆新年、元宵、清明、兒童、母親、端午、父親、七夕、中元、教師、中秋、國慶、重陽、萬聖、感恩、聖誕與跨年，也可自訂小節日。
- 農曆與移動節日顯示為年度日期規則，不固定寫死同一國曆日期。
- 圖片 API 未設定時顯示中文設定指引；不得顯示假成功或自動使用未確認圖片。
- 生成只進入預覽，尚未儲存、排程或推播。

## 不在本次範圍

- 不改 LINE 官方帳號 Rich Menu。
- 不更換或重新生成每日平安 Logo。
- 不在沒有管理員按下生成時自動產生圖片，也不自動推播給任何會員。
- 不修改既有每日排程與里程碑判斷規則。
