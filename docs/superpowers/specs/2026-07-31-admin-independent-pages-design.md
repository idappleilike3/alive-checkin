# 管理後台獨立分頁設計

## 目標

將目前單一長頁面的管理後台改成桌機左側分層導覽、手機抽屜選單，以及右側單一內容頁。管理登入、會員資料、營運資料與既有 API 保持不變。

## 導覽架構

- 營運管理
  - 營運總覽
  - 數據分析
    - 流量分析
    - LINE 訊息用量
- 會員與守護
  - 會員管理
  - 守護營運
- 安全與通知
  - 緊急事件
- 商業營運
  - 封測管理
  - 方案與訂單
- 客服與系統
  - 客服與隱私
  - 測試中心
  - SEO 管理
  - 系統設定

導覽最多三層。子選單預設收合；目前頁面所屬分類自動展開並以底色、粗體及 `aria-current="page"` 標示。

## 頁面路由

沿用 `/admin` 管理入口，以 `page` 查詢參數提供可重新整理、可返回的獨立網址：

- `/admin?page=operations`
- `/admin?page=members`
- `/admin?page=guardian-operations`
- `/admin?page=incidents`
- `/admin?page=beta-program`
- `/admin?page=orders`
- `/admin?page=support`
- `/admin?page=analytics`
- `/admin?page=line-cost`
- `/admin?page=test-center`
- `/admin?page=seo`
- `/admin?page=system`

無參數或不合法參數一律顯示營運總覽。換頁使用正常連結，不以錨點捲動。

## 顯示與響應式

- 桌機：固定 280px 左側選單，右側只顯示目前頁面。
- 手機：左上角 `☰ 功能選單` 開啟側邊抽屜，選頁後自動關閉。
- 一般內文不得小於 16px；導覽與按鈕不得小於 16px；說明文字不得小於 15px。
- 觸控按鈕最低高度 48px。
- 表格保留原欄位並允許水平捲動，不壓縮成難以閱讀的小字。
- 登入前只顯示登入面板；登入後才顯示導覽與內容。

## 相容與安全

- 不修改資料庫、管理權限、登入 Session、CSRF 或既有管理 API。
- 保留所有現有 DOM id，避免既有資料渲染與操作事件失效。
- 同一個 id 不得重複；現有重複的 `lineMessagesUsed` 必須在本次整理中消除。
- 不使用使用者輸入產生 HTML；頁面選擇只接受固定白名單。

## 驗收

- 12 個頁面網址都只顯示對應內容。
- 瀏覽器返回、前進與重新整理保留所在頁面。
- 桌機左側選單與手機抽屜都能操作。
- 目前頁面及所屬分類有清楚標示。
- 原有管理後台測試、Python 測試及新增介面測試全部通過。
