# 後台系統安全中心設計

## 目標

在既有上鎖後台新增「系統安全中心」，讓非工程背景管理者可以快速知道：

- 哪些雲端服務正在付費、何時續費、用途為何。
- 免費或試用服務已使用第幾天、剩幾天、未升級會造成什麼影響。
- 正式資料是否存放在耐久資料庫、最後一次備份是否成功、能否還原。
- LINE、排程、管理員登入與個資流程是否正常。
- 今天需要處理什麼，以及處理後留下什麼紀錄。

後台只呈現必要狀態，不顯示密碼、Token、資料庫連線字串或 R2 Secret。

## 介面架構

新增一個主導覽項目「系統安全」，首頁先顯示四張大型狀態卡：

1. **資料庫安全**：Postgres／非耐久儲存、Free／付費、已使用天數、到期日。
2. **異地備份**：最後成功時間、距今時數、R2 連線、最近還原演練。
3. **服務與續費**：本月預估支出、下一筆續費、逾期或尚未升級項目。
4. **資安維護**：高風險、中風險與今日待辦數。

顏色只作輔助，所有狀態同時顯示文字：

- 綠色「正常」。
- 黃色「需要留意」。
- 紅色「立即處理」。
- 灰色「尚未設定／無法確認」。

每張卡提供單一主要按鈕，例如「查看處理步驟」、「立即備份」或「記錄已付款」。手機版採單欄、桌面版最多兩欄，重要按鈕固定在可見區，不要求捲到底部才能儲存。

## 付費服務與升級提醒

### 服務台帳

後台可新增及編輯下列欄位：

- 服務名稱，例如 Render Web、Render Postgres、Cloudflare R2、LINE Official Account。
- 方案名稱與狀態：免費、試用、付費、已取消。
- 計費週期：每月、每年或一次性。
- 金額與幣別。
- 開始日、續費日、試用／免費到期日。
- 付款方式備註；不得保存完整卡號或安全碼。
- 用途、管理頁連結與負責人。
- 自動續費是否開啟。
- 最後付款日、付款結果與非敏感收據備註。

所有新增、修改、標記付款與取消操作寫入管理員稽核紀錄。

### 天數與提醒

系統依開始日及到期日顯示：

- 「目前第 N 天」。
- 「剩餘 N 天」或「已逾期 N 天」。
- 14、7、3、1 天前提醒。
- 到期當日與逾期後每日提醒，直到管理員標記已升級、續費或取消。

Render Free Postgres 的預設規則為建立後 30 天到期；若 Render 政策或實際到期日不同，以管理者輸入的實際日期為準。畫面明確說明：到期後資料庫會無法使用；寬限期結束可能刪除全部會員、守護關係、簽到、付款與客服紀錄。

### 付費決策標示

- **正式收客前必須**：付費耐久 Postgres。
- **正式營運建議**：付費 Web Service，降低休眠造成的登入、SOS 與排程延遲。
- **已選定**：Cloudflare R2 異地備份。
- **不可取代資料庫**：R2 只保存備份，不作即時主資料庫。

## Cloudflare R2 異地加密備份

### 設定

Render 環境變數保存：

- `R2_ACCOUNT_ID`
- `R2_BUCKET_NAME`
- `R2_ACCESS_KEY_ID`
- `R2_SECRET_ACCESS_KEY`
- `BACKUP_ENCRYPTION_KEY`

GitHub、瀏覽器頁面、API 回應與稽核日誌都不得出現上述秘密值。後台只顯示「已設定／缺少」及 Secret 最後輪替日期。

### 每日備份流程

1. 排程取得 Postgres 權威狀態的一致性快照。
2. 建立包含格式版本、建立時間、資料計數與 SHA-256 校驗值的 JSON 封裝。
3. 使用 AES-256-GCM 加密；`BACKUP_ENCRYPTION_KEY` 必須是 Base64 編碼的 32-byte 隨機金鑰，不得只壓縮或 Base64。
4. 上傳到 R2 私有 Bucket，物件名稱不含會員姓名、LINE user ID 或電話。
5. 上傳後重新讀取 metadata，核對大小與校驗值。
6. 記錄成功／失敗、耗時、大小、版本及錯誤分類，不記錄秘密或個資內容。
7. 備份失敗時最多重試 3 次並採指數退避；仍失敗則在後台顯示紅色警示。

保留策略預設：

- 每日備份保留 35 天。
- 每月第一份備份保留 12 個月。
- 刪除過期備份前先確認至少存在一份近期成功且已驗證的備份。

### 手動操作與還原

- 「立即備份」需要有效管理員工作階段與 CSRF 驗證。
- 「下載加密備份」只提供原始加密檔；一般瀏覽器不直接解密客戶資料。
- 「驗證備份」在隔離暫存區解密、驗證格式與資料計數，不覆蓋正式資料。
- 「正式還原」採兩段式確認，先建立還原前備份，再由管理員輸入畫面顯示的一次性確認字串。
- 還原成功後重新啟動健康檢查並留下完整稽核紀錄。

## 資料庫安全檢查

每次後台載入及排程每日檢查：

- `DATABASE_URL` 是否設定，但不回傳其內容。
- 實際連線、讀取與交易測試是否成功。
- 權威後端是否為 Postgres，`durable=true`。
- 最近一次成功寫入時間與資料計數是否合理。
- 是否誤退回本機 SQLite／暫存磁碟。
- 備份距今是否超過 26 小時。
- 最近一次還原演練是否超過 30 天。
- 免費／試用資料庫是否接近到期。

若偵測到正式環境使用非耐久儲存：

- 後台顯示紅色警示。
- 禁止執行可能造成大量覆寫的管理操作。
- 一般簽到與 SOS 不因檢查服務短暫失敗而直接中斷，但要留下事件並通知管理者。

## 資安維護項目

後台提供可勾選、可排程、具證據欄位的維護清單：

| 項目 | 頻率 | 後台檢查／紀錄 |
|---|---:|---|
| 備份成功與校驗 | 每日 | 最後成功時間、大小、校驗結果 |
| 異地還原演練 | 每月 | 演練日期、結果、資料計數 |
| 管理員登入異常 | 每日 | 失敗次數、鎖定事件、來源摘要 |
| LINE Webhook 簽章 | 每日 | 最近成功驗證時間、失敗次數 |
| LINE Token 健康 | 每日 | API 健康結果；不保存 Token 原文 |
| 排程健康 | 每日 | 最後執行時間、漏跑與重試 |
| 套件漏洞掃描 | 每週 | 高／中風險數、修復版本 |
| 管理員密碼檢視 | 每 90 天 | 最後更新日，不保存密碼 |
| Session Secret 輪替 | 每 90 天 | 最後輪替日、是否逾期 |
| R2 金鑰輪替 | 每 90 天 | 最後輪替日、連線驗證 |
| 權限與管理員名單 | 每月 | 新增、移除與覆核紀錄 |
| 個資匯出／刪除申請 | 每週 | 待處理件數、期限與完成證據 |
| 服務續費與發票 | 每月 | 應付、已付、逾期與收據備註 |
| 部署與回歸測試 | 每次部署 | commit、測試數、結果、部署時間 |

維護任務可標記「完成」、「略過」或「需要協助」。略過必須填寫原因；系統保留最近 12 個月紀錄。

## API 與資料模型

新增概念資料：

- `infrastructure_subscriptions`：付費與續費台帳。
- `security_health_snapshots`：每日安全檢查摘要。
- `backup_runs`：R2 備份、驗證與還原結果。
- `maintenance_tasks`：週期、到期日、完成狀態與證據。
- `security_events`：不含秘密值的安全事件。

所有管理 API 沿用現有 Session＋CSRF 保護及稽核機制。清單 API 只回傳畫面必要欄位；任何欄位名稱包含 password、secret、token、key、authorization 或 cookie 時一律遮蔽。

## 通知

第一階段以後台紅／黃警示為主，並使用既有管理通知管道發送：

- 資料庫將到期或連線失敗。
- 連續兩次 R2 備份失敗。
- 超過 26 小時沒有成功備份。
- 超過 30 天未做還原演練。
- LINE Token／Webhook／排程異常。
- 服務即將續費或付款逾期。

通知不得包含連線字串、Token、客戶姓名、電話或 LINE user ID。

## 驗收

- 非管理員無法讀取或修改安全中心資料。
- CSRF、登入鎖定與稽核測試通過。
- API、HTML 與日誌不洩漏秘密值。
- 能正確顯示第 N 天、剩餘日、逾期日及 14／7／3／1 天提醒。
- R2 備份具加密、校驗、重試、保留策略與異地還原驗證。
- 關閉或填錯 R2 憑證時，正式資料不受損且後台顯示可理解的處理方式。
- 正式環境誤用非耐久儲存時顯示紅色警示並限制危險管理操作。
- 手機與桌面均可在不過度捲動的情況完成付款紀錄、備份與維護任務。
- 完整 Python、前端行為、安全掃描及按鈕測試通過後才建立 PR 與部署。
