# 後台完整圖文卡預覽設計

## 目標

後台「圖文卡設定與預覽」必須忠實呈現使用者提供的直式整張圖片，不得固定裁成 4:5。品牌與操作按鈕須與核准參考圖一致。

## 視覺規格

- 主圖使用原始比例完整顯示，CSS 使用 `height: auto` 與 `object-fit: contain`，不使用固定 `aspect-ratio` 裁切。
- 品牌列固定顯示每日平安原始 Logo 與「每日平安」。
- 五顆按鈕依序為：
  1. 每日平安 Logo＋「我平安」，綠色。
  2. 盾牌圖示＋「安全守護」，藍色。
  3. SOS 對話框圖示＋「需要幫忙」，紅色。
  4. 鈴鐺圖示＋「查看今日安心提醒」，金色。
  5. 守護人圖示＋「邀請親友成為守護人」，棕色。
- 本機即時預覽與指定會員預覽必須使用同一組 CSS 與按鈕結構。

## 資料與安全

- 保留既有每日平安 Logo 固定不可替換的規則。
- 第五顆按鈕連至既有一鍵邀請頁 `/liff/share-invite.html`。
- 儲存仍只建立圖文卡範本，不會立即推播。

## 驗收

- 行為測試確認不存在 `aspect-ratio: 4 / 5` 與 `object-fit: cover` 的主圖裁切規則。
- 行為測試確認五顆按鈕、五種圖示、五種配色及品牌 Logo 均存在。
- Python 個人化卡片測試確認預設範本含第五顆邀請按鈕，且渲染顏色順序一致。
