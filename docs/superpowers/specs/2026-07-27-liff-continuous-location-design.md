# LINE 前景持續定位設計

## 目標

安全守護開啟後，只要 LINE LIFF 頁面仍在前景開啟，就持續取得使用者位置並更新守護人看到的最新位置。

## 行為

- 首次定位成功並開啟安全守護後啟動 `watchPosition`
- 至少相隔 20 秒，且移動約 20 公尺才上傳新座標
- 即使沒有明顯移動，每 60 秒仍上傳一次心跳位置
- 連續 2 分鐘沒有成功上傳時，畫面顯示「定位可能中斷」
- 每次上傳使用既有 `refresh_only`，不得重複推播「安全守護已開啟」
- 使用者停止安全守護、方案時段結束或頁面卸載時停止定位監測
- 只保存最新位置，不新增移動軌跡
- LINE 切到背景、手機鎖屏或關閉頁面後不保證更新

## 錯誤處理

- 單次更新失敗不立即終止監測，畫面提示將自動重試
- 權限遭拒時停止監測並提示使用者檢查定位權限
- 後端回報守護已失效時停止監測並同步關閉前端狀態

## 驗收

- 能啟動及停止 `watchPosition`
- 靜止時不會每次 GPS 回呼都呼叫 API
- 移動達門檻或心跳到期才更新
- 停止後的舊回呼不會再上傳
- 守護人端顯示最後更新時間與超過 2 分鐘的中斷狀態
