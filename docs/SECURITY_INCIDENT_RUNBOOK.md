# 每日平安資安事故處理手冊

## 啟動條件

發現金鑰外洩、異常登入、越權讀取、推播或金流暴增、會員個資外洩、備份失敗或服務被植入不明程式時，立即啟動本手冊。不要把 Token、電話、地址、座標或完整 LINE UID 貼入聊天室與一般工單。

## 第一階段：15 分鐘內止血

1. 記錄發現時間、值班人、受影響服務與不含敏感值的錯誤類別。
2. 在 Render 暫停非緊急推播、付款、退款及帳號重綁入口；SOS 若未遭濫用則維持。
3. 對疑似外洩的 LINE、金流、資料庫、R2、SMTP 或管理員金鑰，在原服務平台撤銷並重新產生；不得把新值提交 Git。
4. 使全部管理員 Session 失效並要求重新登入。
5. 保留日誌、部署 ID、Git commit 與資料庫快照；不得刪除或覆寫證據。

## 第二階段：確認範圍

1. 依請求追蹤碼、稽核紀錄與去識別化事件確認最早／最後異常時間。
2. 核對是否涉及會員資料、守護關係、電話、地址、定位、SOS、訂單或退款。
3. 比對部署前後檔案 SHA、依賴版本、管理員操作與資料筆數。
4. 若疑似資料外洩，交由負責人評估法律通知義務與通知時間。

## 第三階段：復原

1. 只從已驗證、加密且完成還原測試的備份復原到隔離環境。
2. 完成根因修正、負向測試、完整回歸及安全標頭驗收後才重新部署。
3. 先恢復讀取與 SOS，再逐步恢復登入、推播、金流及後台寫入。
4. 正式站非破壞 smoke test 通過後，記錄新 deploy ID、commit 與恢復時間。

## 結案與預防

事故紀錄必須包含時間軸、影響範圍、根因、輪替項目、復原證據、會員通知決定及後續負責人。每季至少演練一次管理員 Session 失效、金鑰輪替與備份還原；只有備份成功、沒有實際還原證據，不算完成。
